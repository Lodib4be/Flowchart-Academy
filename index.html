Step-by-step instructions

  2. Input a number – use the input/output symbol.

ABOUT THE LEARNING RESOURCE

About Flowchart Academy

Development and Evaluation of a Web-Based Learning Resource on Basic Flowchart for First-Year BTVTEd-Computer Programming Students

This web-based learning resource is designed to support students in understanding the basic concepts, symbols, rules, and applications of flowcharts. It provides organized lessons, visual examples, guided tutorials, practice activities, and an assessment quiz to encourage active and self-paced learning.

General Objective

To provide an accessible and interactive learning resource that helps students develop foundational knowledge and skills in creating and interpreting basic flowcharts.

Target Learners

First-Year Bachelor of Technical-Vocational Teacher Education (BTVTEd), major in Computer Programming students.

Specific Learning Outcomes
  • Define and explain the purpose of a flowchart.
  • Identify basic flowchart symbols and their functions.
  • Apply the basic rules in constructing a flowchart.
  • Interpret simple flowchart diagrams.
  • Construct a basic flowchart to solve a given problem.
